## Playback architecture

NAudioMusicManager.Play suppresses active, fading, and already queued duplicates. Update constructs NAudioTrack only when the queue starts. PlayOnce continuation and PlayBookmark share that queue. A hook immediately before construction can cover every configured cue while preserving the game's duplicate suppression. Bookmark restoration must keep the same selected file because bookmarks are PCM byte offsets.

MCache accepts .mp3 and .ogg only. OGG is decoded by the installed NVorbis adapter; WAV/FLAC are not accepted. First manager build imports Ogg Vorbis only. Packed vanilla MP3 tracks remain in bgm.dat.

Replacement metadata must reset DatOffset/DatLength, PlayStart and nested LoopPoint, and restore the original boxed TrackMetadata for empty/disabled pools. Leaving original loop bounds on an untagged replacement is unsafe. Native transitions, saved bookmarks and in-game soundtrack atlas need testing.
